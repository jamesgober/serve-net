# serve-net v0.8.2

**A reply can be read back.** `reply.parts()` now has read-only accessors for what the service set: `status()`, `header()`, `header_all()`, `headers()`, `body()`, `is_streamed()`, `closes()`, and `retry_after()`. That is what a cache needs to keep a whole page, and it makes tests shorter.

```rust
let site = serve_net::handler(|_req, reply| {
    reply.html(200, "<p>hi</p>").header("cache-control", "public, max-age=60");
    let page = reply.parts();
    assert_eq!(page.status(), 200);
    assert_eq!(page.header("Cache-Control"), Some(&b"public, max-age=60"[..]));
    assert_eq!(page.body(), b"<p>hi</p>");
});
```

The fields serve-net adds when it writes the reply (`content-length`, `date`, `retry-after`, `connection`) are not among `headers()`. A static body reads back as the same bytes, with no copy.

Nothing else changes. Upgrade by changing the version to `0.8.2`.
